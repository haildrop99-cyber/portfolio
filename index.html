    Key points

    코드는 저장소의 실제 코드에서 발췌했습니다.

    // _worker.js — 매장 코드는 D1에만 있고 공개 API 응답에는 포함하지 않는다
if (p === '/api/redeem' && request.method === 'POST') {
  const { phone, storeKey, code } = await request.json();
  if (!storeKey || !code) return json({ error: 'storeKey/code required' }, 400);

  const row = await env.DB
    .prepare(`SELECT name, code FROM stores WHERE key = ?1`)
    .bind(storeKey).first();
  if (!row) return json({ error: 'store not found' }, 404);

  if (String(code).trim().toUpperCase() !== String(row.code).trim().toUpperCase())
    return json({ ok: false, reason: 'invalid_code' });

  await logEvent(env, phone, 'stamp', row.name, '코드인증');  // 서버가 스탬프를 기록
  return json({ ok: true });
}
    • 서버에서 검증하는 스탬프매장 코드는 서버에만 두고, 확인된 경우에만 스탬프를 기록합니다.
    • 끊겨도 남는 진행 상황기기에 먼저 저장한 뒤 서버와 동기화해, 같은 전화번호로 다른 기기에서도 이어집니다.
    • 운영자 대시보드참여 통계, 참여자와 이용기록 검색, CSV 다운로드, 빙고판 수정을 한 화면에서 처리합니다.
    • 운영 중 문제 해결이벤트 기간에 발견한 스탬프 저장 충돌과 진행 상황 덮어쓰기 문제를 바로 고쳤습니다.

    How it works

    서비스 링크가 비공개라, 실제 화면 대신 청중이 보게 되는 흐름을 예시 문장으로 재현했습니다. "발표 재생"을 누르면 발표자의 말과 번역 자막이 차례로 나타나고, "발표 후 기록"에서는 끝난 발표를 다시 읽는 화면을 볼 수 있습니다.

    청중 화면 재현예시

    발표자 · 한국어

      흐름을 보여주기 위한 재현 화면입니다. 예시 문장이며, 실제 서비스 화면이나 DeepL 번역 결과가 아닙니다.

      What it does

      • 실시간 번역 자막발표자가 말하는 내용을 DeepL 엔진으로 번역해 청중 화면에 바로 보여줍니다.
      • 번역 음성자막과 함께, 번역된 내용을 음성으로도 들을 수 있습니다.
      • 접속자마다 다른 언어같은 링크로 들어온 청중이 각자 자기 언어로 발표를 따라갑니다.
      • 발표 후 다시 보기발표가 끝난 뒤에 접속해도 발표자가 어떤 내용을 말했는지 확인할 수 있습니다.

      How it's built

      외부 JS 라이브러리 없이 브라우저 기본 API만으로 인터랙션을 만들었습니다.

      // 숫자 카운트업 — 화면에 60% 이상 보일 때 한 번만 실행
const cio = new IntersectionObserver(es => es.forEach(e => {
  if (!e.isIntersecting) return;
  cio.unobserve(e.target);
  const el = e.target, to = +el.dataset.to, t0 = performance.now();
  (function tick(t){
    const p = Math.min((t - t0) / 1400, 1);
    el.textContent = Math.round(to * (1 - Math.pow(1 - p, 3)));   // ease-out cubic
    if (p < 1) requestAnimationFrame(tick);
  })(t0);
}), { threshold: .6 });
      • IntersectionObserver섹션 등장, 대시보드 목업 재생, 숫자 카운트업을 스크롤 이벤트 대신 관찰자로 처리합니다.
      • Canvas 파티클 배경점들이 움직이며 가까워지면 선으로 이어지는 배경을 requestAnimationFrame으로 그립니다.
      • SVG 로고 3종심볼, 워드마크, 전체 로고를 1.5–5KB의 SVG로 넣어 어떤 해상도에서도 선명합니다.
      • 파일 하나로 배포HTML, CSS, JS를 한 파일에 담아 요청 수를 줄이고 어디에나 쉽게 올릴 수 있게 했습니다.
